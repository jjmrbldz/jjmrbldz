### What I do

In tech since **2017**, building software since **2020** — I came to engineering the long way around: IT technician, then graphic designer, then UI/UX, then front end, and now full stack across the whole product. That path is the point: I care how a thing looks *and* how it holds up in production.

- **Mobile** — cross-platform apps with React Native + Expo, taken through App Store and Google Play review to release
- **Web** — React, Next.js (App Router), and TypeScript with Tailwind, ShadCN, and Mantine
- **Backend** — REST APIs in NestJS and Fastify, over PostgreSQL (Prisma) and MySQL/MariaDB (Drizzle), with Redis caching and BullMQ job queues
- **Design** — UI/UX and visual design, so specs arrive as working interfaces instead of open questions
- **End to end** — I own features from schema design through deployment rather than handing off at the seams

**Currently:** engineering at **DAO Labs** across a four-surface platform — a NestJS/PostgreSQL API, a Next.js web app, an admin console, and an Expo mobile app. Recent work has spanned an insert-only transaction ledger for the points system, analytics and reporting endpoints, Web3 wallet auth, scheduled scanners with health monitoring, and real-time updates over SSE. Also building the **SplenDoor** mobile app with the [Stackhaven](https://www.stackhaven.tech/) team.

A note on the repos below: most of my day-to-day work lives in private client and employer repositories, so what's public here is a subset.
